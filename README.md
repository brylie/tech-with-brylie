Tech With Brylie explores AI, open-source tools, and the ideas reshaping how we build software. This repository is the production workspace behind the channel: a place to develop explainers in the open, turn experiments into visual stories, and share the code that makes them possible.

The aim is simple: help you understand what is new—and make something meaningful with it.

## What we are building

- **Visual explainers** that make technical ideas easier to see, not just read about.
- **Practical experiments** with AI and open-source tools.
- **Thoughtful engineering**: reproducible source, clear documentation, and lessons that extend beyond a single video.

Manim powers the animated visual layer, while Python, uv, and mise keep the development environment consistent across contributors.

## Follow the work

New videos and experiments will be published on [YouTube](https://www.youtube.com/@brylie). The first project in development is a channel introduction: a concise, narrated Manim production that establishes the visual language for future explainers.

If you find the work useful, subscribe, share a topic you would like explained, or open an issue or pull request with an improvement.
